ДНЕВНОЙ БЮДЖЕТ — прототип 0.1

Это исходный проект, НЕ готовый APK. В этой среде нет JDK, Android SDK и Gradle:
проект не компилировался и не проверялся на реальном телефоне.

Сборка:
1. Установите актуальную Android Studio на компьютер.
2. Распакуйте архив и откройте папку DayBudget как проект.
3. Используйте JDK 17, Android SDK Platform 35, Gradle 8.11.1.
   Gradle Wrapper не включён: выберите локальную установку Gradle 8.11.1
   в настройках Gradle Android Studio либо выполните установленным Gradle:
   gradle wrapper --gradle-version 8.11.1
4. Выполните синхронизацию. Для скачивания инструментов сборки нужен интернет.
5. Build > Generate App Bundles or APKs > Generate APKs (название зависит от версии IDE).
6. Установите полученный debug APK на телефон.

Первый запуск:
- Введите начальный баланс карты и наличных.
- В настройках выберите день ежемесячной зарплаты через календарь.
- Разрешите доступ к уведомлениям.
- Проверьте имя пакета банковского приложения: по умолчанию com.idamob.tinkoff.android.
  Это предположение; установленная сборка может иметь другое имя.
- Если Android блокирует доступ для установленного вручную приложения,
  изучите системное предупреждение. Приложению нужен только доступ к уведомлениям,
  оно НЕ требует специальных возможностей, администратора или отключения блокировки.

Проверка на Samsung:
1. Нажмите тест распознавания в настройках: ожидается 163 507,26 ₽.
2. Дождитесь новой реальной операции банка и уведомления с «Доступно … ₽».
3. Проверьте баланс на вкладке «Карта».
4. Повторите с заблокированным экраном, затем проверьте результат после разблокировки.
5. Если не работает, проверьте доступ к уведомлениям, пакет банка, полный текст
   уведомления и настройки фоновой работы Samsung. Не отключайте защиту телефона.

Принцип работы:
- Служба уведомлений сохраняет остаток в собственной локальной базе (SharedPreferences).
  Окно приложения не открывается; постоянный foreground service не используется.
- Берётся положительный остаток после «Доступно», с копейками. Не сумма покупки.
- В текущем прототипе отрицательный остаток не распознаётся.
- Если банк не прислал доступный текст с остатком, баланс остаётся прежним.
- Обновление по одинаковому уведомлению не вычитает расход повторно.
- Более старое по postTime уведомление игнорируется. Если банк повторно публикует
  старую операцию с новым временем, эта защита не гарантирует правильный порядок.
- История уведомлений, полный текст и реквизиты не сохраняются.
- Приложение без INTERNET-разрешения. Резервное копирование отключено.
- Все 100 000 рублей резерва исключены из логики: переносится весь остаток банка.
- Наличные изменяются вручную: установка остатка, расход, пополнение.
  Для снятия с карты вручную увеличьте наличные, банк сам обновит карту уведомлением.
- Лимит = (карта + наличные) / число календарных дней до следующей зарплаты,
  с округлением вниз до копейки. Сегодня включается, день зарплаты исключается.
- В сам день зарплаты расчёт уже ориентируется на следующий месяц.
  Зарплата сама не начисляется: дождитесь уведомления либо обновите баланс вручную.
- Если выбранного числа нет в месяце, используется последний день месяца.
- Только ежемесячный день зарплаты; несколько зарплатных дат не поддерживаются.
- Виджета, экспорта, журнала операций и удалённого сервера в версии 0.1 нет.

Ограничения:
Android может скрывать чувствительное содержимое уведомлений. Доступность текста
на Android 17 и работу службы после перезагрузки/в энергосбережении необходимо
проверить на Samsung S25 Ultra. Не гарантируется работа до первой разблокировки
после перезагрузки, после принудительной остановки или отзыва разрешения.
Это не банковская интеграция: при пропущенном уведомлении баланс может устареть.
Не считайте показанный лимит гарантией доступности денег.
